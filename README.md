# 20고개 (Twenty Questions) — 2~8인 실시간 멀티플레이

React + Vite 클라이언트와 Node WebSocket 서버로 만든 실시간 스무고개 게임입니다.
매 라운드 한 명이 출제자가 되어 단어를 정하고, 나머지가 예/아니오 질문 20개 안에 정답을 맞힙니다.

## 실행

```bash
npm install
npm run dev      # 서버(3001) + Vite 개발 서버(5173) 동시 실행 → http://localhost:5173
```

배포용 실행(서버 하나가 정적 파일과 WebSocket을 모두 처리):

```bash
npm run build
npm start        # http://localhost:3001  (PORT 환경변수로 변경 가능)
```

### 폰에서 같이 하기 (같은 와이파이)

두 실행 방식 모두 LAN에 열려 있으므로, PC의 내부 IP를 확인해 폰 브라우저로 접속하면 됩니다.

```bash
npm start                 # 또는 npm run dev
# macOS/Linux: ipconfig getifaddr en0  또는  hostname -I
# 폰에서 http://<PC의 내부 IP>:3001  (dev 모드면 :5173)
```

방장이 만든 **4자리 방 코드**를 공유하면 각자 폰에서 참가합니다.
서로 다른 네트워크(각자 집, LTE)에서 하려면 공개 주소가 필요합니다 —
WebSocket을 지원하는 호스팅에 배포하거나 `cloudflared`/`ngrok` 같은 터널을 `npm start` 앞에 붙이세요.
(터널은 반드시 `npm start`(3001)에 연결하세요. Vite 개발 서버는 외부 도메인 접근을 차단합니다.)

## 테스트

```bash
npm test         # 33개: 게임 규칙 단위 테스트 + 실제 WebSocket 통합 테스트
```

통합 테스트는 실제 서버를 띄워 클라이언트 여러 개를 붙이고, 한 라운드를 끝까지 진행하면서
**정답 단어가 추측자에게 전송되지 않는지**까지 확인합니다.

## 게임 규칙

| 항목 | 값 |
| --- | --- |
| 인원 | 2~8명 (게임 시작 후 신규 입장 불가) |
| 라운드 수 | 참가자 수 (모두 한 번씩 출제) |
| 질문 수 | 라운드당 20개 |
| 단어 선택 제한 시간 | 60초 |
| 질문 단계 제한 시간 | 5분 |
| 점수 | 맞힌 사람 +3 / 출제자는 누가 맞히면 +1, 아무도 못 맞히면 +2 |

- 질문은 **선착순 자유 질문**이고, 답변을 기다리는 동안에는 다음 질문을 받지 않습니다.
  (순번제 대신 선택한 이유: 8명 중 한 명이 자리를 비우면 순번제는 판이 멈춥니다.)
- 정답 시도는 서버가 자동 판정합니다. 공백·문장부호·대소문자는 무시합니다.
- 틀린 정답 시도는 질문 1개를 소모합니다.
- 출제자가 나가거나 단어를 못 정하면 그 라운드는 무효(점수 없음)로 처리됩니다.

## 구조

```
server/game.js        게임 규칙 전부. I/O·타이머 없는 순수 함수, 시간은 인자로 주입
server/index.js       WebSocket/HTTP 서버. 연결·방 목록·브로드캐스트·1초 틱만 담당
server/*.test.js      규칙 단위 테스트 + 실제 소켓 통합 테스트
src/useGameSocket.js  자동 재접속, 좌석 복구, 서버 시계 오차 보정
src/screens/          Home(입장) / Game(대기실·출제·질문·결과)
```

설계상 중요한 두 가지:

1. **서버 권위**: 모든 상태는 서버가 소유하고, `viewFor(room, playerId)`가 플레이어별로
   볼 수 있는 것만 화이트리스트로 골라 내보냅니다. 정답 단어는 출제자 본인과
   라운드 종료 이후에만 포함됩니다. 클라이언트로 내려가지 않으니 DevTools로도 볼 수 없습니다.
2. **좌석 복구**: 입장할 때 받은 토큰을 `sessionStorage`에 저장해 두고, 새로고침이나 연결 끊김 뒤
   같은 자리로 돌아옵니다. 게임 중 이탈한 사람의 자리는 남겨 두고, 대기실에서는 정리합니다.

## 알려진 제한과 위험

- **상태는 서버 메모리에만 있습니다.** 서버를 재시작하면 진행 중인 모든 방이 사라집니다.
  또한 서버 여러 대로 확장하면 방이 공유되지 않습니다(외부 저장소나 sticky session 필요).
- **인증이 없습니다.** 방 코드 4자리(약 100만 조합)만 알면 누구나 들어옵니다.
  공개 인터넷에 올린다면 코드 길이를 늘리거나 입장 제한을 두세요.
- **도배 방지가 없습니다.** 길이 제한만 있고 속도 제한은 없습니다.
- **정답 판정은 문자열 비교입니다.** "야옹이"는 "고양이"의 정답으로 인정되지 않습니다.
  동의어를 허용하려면 출제자 수동 인정 기능이 필요합니다.
- **출제자의 예/아니오 판정은 검증할 수 없습니다.** 사람의 선의를 전제로 합니다.
- 아무도 없는 방은 10분 뒤 정리됩니다. 제한 시간은 서버가 1초 간격으로 확인합니다.
