# 알려진 제한과 위험

[← README로](../README.md)

- **상태는 서버 메모리에만 있습니다.** 서버를 재시작하면 진행 중인 모든 방이 사라집니다.
  또한 방 목록이 프로세스 안에 있어서, 서버를 여러 대로 늘리면 방이 공유되지 않습니다.
  Render 무료 플랜에서는 15분 유휴 후 슬립에서 깨어날 때도 같은 일이 일어납니다.
- **방이 공개됩니다.** 방 코드가 없으므로 서버에 접속한 사람은 누구나 목록을 보고 들어옵니다.
  사적인 방이 필요하면 접속 자체를 제한하거나(사내망, 터널 인증) 코드 방식을 되살려야 합니다.
- **동시 수용 인원은 24명(8명 × 3방)** 입니다. 더 필요하면 `ROOM_COUNT`를 올리세요.
- **폰에서 화면을 잠그면 연결이 끊깁니다.** 5초(`RECONNECT_GRACE_MS`) 안에 돌아오면 아무 영향이 없고,
  그 뒤에도 좌석은 토큰으로 복구되지만, 그보다 오래 끊긴 사람이 그 라운드의 출제자였다면 라운드는 무효가 되고,
  남은 접속자가 2명 미만이 되면 게임이 종료됩니다.
- **도배 방지가 없습니다.** 길이 제한만 있고 속도 제한은 없습니다.
- **정답 판정은 문자열 비교입니다.** "야옹이"는 "고양이"의 정답으로 인정되지 않습니다.
- **출제자의 예/아니오 판정은 검증할 수 없습니다.** 사람의 선의를 전제로 합니다.
- **웹 폰트는 외부 CDN에서 받습니다.** (Google Fonts의 Jua, jsDelivr의 Pretendard)
  차단된 네트워크에서는 시스템 서체로 표시됩니다. 동작에는 영향이 없습니다.
