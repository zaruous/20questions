# 게임 규칙 (상세)

[← README로](../README.md)

## 한 판의 흐름

1. **대기실** — 방장이 참가자 카드를 탭해 **첫 출제자**를 고를 수 있습니다. 고르지 않으면 입장 순서입니다.
   출제자는 매 라운드 그 순서대로 돌아가므로, 첫 사람을 정하는 것이 곧 순서를 정하는 것입니다.
   대기실 화면에 최종 순서(예: `지연 → 민수 → 철수 → 영희`)가 미리 표시됩니다.
2. **단어 선택** — 출제자가 60초 안에 단어를 정합니다. 단어는 출제자 화면에만 보입니다.
3. **질문** — 나머지가 예/아니오로 답할 수 있는 질문을 합니다. 라운드당 20개.
   출제자는 `예 / 아니오 / 애매함` 중 하나로 답합니다.
4. **정답** — 언제든 정답을 외칠 수 있습니다. 서버가 자동 판정하며, 틀리면 질문 1개를 소모합니다.
5. **라운드 종료** — 누가 맞히거나, 질문을 다 쓰거나, 5분이 지나면 끝납니다.
   15초 뒤 자동으로(또는 방장이 바로) 다음 라운드로 넘어갑니다.
6. **게임 종료** — 모두가 한 번씩 출제하면 끝. 방장이 "같은 사람들과 다시 하기"를 누르면 대기실로 돌아갑니다.

## 숫자

| 항목 | 값 |
| --- | --- |
| 인원 | 방당 2~8명 |
| 라운드 수 | 참가자 수 (모두 한 번씩 출제) |
| 질문 수 | 라운드당 20개 |
| 단어 선택 제한 시간 | 60초 |
| 질문 단계 제한 시간 | 5분 |
| 결과 화면 | 15초 뒤 자동 진행 |
| 점수 | 맞힌 사람 **+3** / 출제자는 누가 맞히면 **+1**, 아무도 못 맞히면 **+2** |
| 길이 제한 | 닉네임 12자 · 단어 40자 · 질문/정답 200자 |

## 세부 규칙

- 질문은 **선착순 자유 질문**이고, 답변을 기다리는 동안에는 다음 질문을 받지 않습니다.
  순번제 대신 선택한 이유: 8명 중 한 명이 자리를 비우면 순번제는 판이 멈춥니다.
- 정답 판정은 **공백·문장부호·대소문자를 무시한 문자열 비교**입니다.
  `" 고양이 "`, `"고양이!"`는 정답이지만 `"야옹이"`는 아닙니다.
- 출제자가 나가거나 단어를 정하지 못하면 그 라운드는 **무효**(점수 없음)입니다.
- 연결이 끊긴 사람의 출제 차례는 건너뜁니다. 남은 접속자가 2명 미만이면 게임이 끝납니다.
- 첫 출제자 지정은 **방장만, 대기실에서만** 할 수 있습니다.
  지정된 사람이 대기실에서 나가면 자동으로 풀리고, 게임을 다시 시작할 때 그 사람이 남아 있으면 지정이 유지됩니다.

## 방

| 항목 | 값 |
| --- | --- |
| 방 개수 | **3개 고정** (`ROOM_COUNT` 환경변수로 변경) |
| 입장 방법 | 첫 화면 방 목록에서 선택 (방 코드 없음) |
| 게임 중인 방 | 목록에 잠긴 상태로 표시되고 새 사람은 못 들어옴 |
| 빈 방 | 게임이 끝나고 다 나가면 즉시, 진행 중이던 판이면 60초 뒤 대기실로 반납 |
| 서버 전체 동시 참가자 | 최대 24명 (8명 × 3방) |

방은 서버 시작 시 만들어지고 이후 생성·삭제되지 않습니다. 사람이 다 나간 방을 자동으로 되돌리지 않으면
3개뿐인 자리가 '게임 중'인 채로 영영 잠기기 때문입니다.
